# Keybind Bug Fixes

Keybind Bug Fixes is a **100% client side** Minecraft mod, that fixes keybind-related bugs, adds keybind-related tweaks and new keybinds.

**Every feature is configurable.**

## Features
### Bug Fixes:
- Fix pressing F3 twice to open the debug screen [[MC-183776]](https://bugs.mojang.com/browse/MC-183776)
- Fix game mode switcher reset on death [[MC-259571]](https://bugs.mojang.com/browse/MC-259571)
- Fix toggle key state reset on death [[MC-263293]](https://bugs.mojang.com/browse/MC-263293)
- Fix pick key dragging in inventory [[MC-117771]](https://bugs.mojang.com/browse/MC-117771)
- Fix toggle sneak on dismount [[MC-169163]](https://bugs.mojang.com/browse/MC-169163)
- Fix toggle control as modifier
### Tweaks:
- Remove keybind conflicts
### Keybinds:
- `F3` Debug Screen
- `F4` Game Mode Switcher

For a more detailed description, see the [translations file](src/main/resources/assets/keybindbugfixes/lang/en_us.json) or use [Mod Menu](https://modrinth.com/mod/modmenu) alongside the mod.

## Configuration
- Configurations can be changed in-game using [Mod Menu](https://modrinth.com/mod/modmenu). Changes apply without the need to restart Minecraft.
- If you don't want to use Mod Menu, configurations can be found in: `.minecraft/config/keybindbugfixes.json`, however, changes will require a restart of Minecraft to apply.

## Downloading
Stable releases can be downloaded from the [Modrinth](https://modrinth.com/mod/keybindbugfixes) page.
Alternatively, you can build the project from sources by running `./gradlew build`.
